# @fieldmaps/core

The UI-free half of [Field Maps](https://www.fieldmaps.app): the Mahlwinkel airfield's map content (scenarios, points of interest, calibration, OpenStreetMap data, faction emblems) and the math to use it (GPS ↔ map fit, distances and bearings, GPS and compass watchers, basemap themes).

Most apps want [`@fieldmaps/field-map`](../field-map/README.md), the `<field-map>` element built on this. What is in here: [AGENTS.md](./AGENTS.md).
